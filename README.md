# 🧊 PG Reseller Bot

ربات تلگرام **سبک** برای فروش پنل نمایندگی روی **پنل پاسارگارد** خودت. مشتری پنل می‌خرد، ربات برایش یک ادمین جدا روی پاسارگارد می‌سازد و او فقط به بخش ادمین دسترسی دارد.

- 🪶 Python + SQLite، بدون Docker، Postgres و aiogram. رم حدود **۳۵ تا ۵۰ مگ**.
- 🔌 فقط پاسارگارد. آدرس و رمز پنل از داخل ربات داده می‌شود، نه داخل کد.
- 🔒 رمز پنل با Fernet رمزنگاری‌شده در دیتابیس می‌ماند. توکن ربات در لاگ چاپ نمی‌شود.

## 🧊 منوی اصلی
دکمه‌های شیشه‌ای: خرید پنل، حساب کاربری، تست پنل، سوالات متداول، پنل‌های من، کیف پول، پشتیبانی.

## 🛠 مدیریت (`/admin`)
- 🎛 هر دکمه: روشن/خاموش، تغییر اسم، رنگ (آبی/سبز/قرمز)، ایموجی پریمیوم (خود ایموجی را برای ربات بفرست)، جابجایی
- 📦 پلن‌ها (نام، قیمت، روز)
- 🛰 اتصال پنل پاسارگارد و تست ساختار
- 🗂 پنل‌های فروخته‌شده: تعلیق، تمدید، رمز جدید، حذف
- 🧾 رسیدهای کارت‌به‌کارت، 👥 کاربران (موجودی، مسدود)، ⚙️ تنظیمات، 📢 پیام همگانی

## ⚡ نصب
روی سرور Ubuntu/Debian با دسترسی root:

```bash
apt-get update -y && apt-get install -y git
git clone https://github.com/OWNER/REPO.git /opt/pgbot
bash /opt/pgbot/menu.sh
```

گزینهٔ 1 را بزن؛ توکن ربات و آیدی عددی ادمین را می‌پرسد. بعد در ربات `/admin` ← «اتصال پنل» را بزن.

> ⚠️ از فایل `.env` (به‌خصوص `ENCRYPTION_KEY`) بکاپ بگیر. بدون آن رمز ذخیره‌شدهٔ پنل خوانده نمی‌شود.

## ✨ رنگ و ایموجی پریمیوم روی دکمه
رنگ و ایموجی با فیلدهای `style` و `icon_custom_emoji_id` تلگرام روی دکمه‌ها می‌نشیند و به تلگرام به‌روز نیاز دارد. ایموجی پریمیوم روی دکمه فقط وقتی نمایش داده می‌شود که تلگرام برای آن ربات اجازه بدهد.

## ⚠️ وضعیت
- مسیرهای ادمین پاسارگارد (`/api/admin`، `/api/admins`) مطابق ساختار رایج نوشته شده و روی پنل واقعی تست نشده. بعد از اتصال، «تست اتصال و ساختار» را بزن تا مسیرها و فیلدهای واقعی نشان داده شود.
- محدودیت کاربر و حجم برای ادمین هنوز ندارد؛ انقضا را خود ربات اعمال می‌کند (هر ۱۰ دقیقه ادمین منقضی را روی پنل غیرفعال می‌کند).
