# 🧊 PG Reseller Bot

### 🤖 ربات فروش و مدیریت پنل نمایندگی در تلگرام
💎 مخصوص **پنل پاسارگارد (PasarGuard)**

> مشتری پنل می‌خرد، ربات برایش یک ادمین جدا روی پاسارگارد می‌سازد و او فقط به بخش ادمین دسترسی دارد.

- 🪶 Python + SQLite، بدون Docker و Postgres
- 💾 مصرف رم حدود **۳۵ تا ۵۰ مگ**
- 🔌 آدرس و رمز پنل از داخل ربات داده می‌شود، نه داخل کد
- 🔒 رمز پنل با Fernet رمزنگاری‌شده در دیتابیس می‌ماند
- 🙈 توکن ربات در لاگ چاپ نمی‌شود

---

## ✨ امکانات ربات

### 👤 بخش کاربران
- 🛒 **خرید پنل:** انتخاب پلن و ساخت خودکار ادمین روی پاسارگارد
- 🎁 **تست پنل:** دریافت پنل تست
- 👤 **حساب کاربری:** مشاهده اطلاعات حساب
- 💰 **کیف پول:** مشاهده موجودی و شارژ
- 🧾 **شارژ کارت‌به‌کارت:** ارسال رسید و تأیید توسط ادمین
- 📦 **پنل‌های من:** مشاهده وضعیت، انقضا و حجم پنل‌ها
- ❓ **سوالات متداول**
- 🎧 **پشتیبانی:** ارتباط مستقیم با ادمین

### 🛠 پنل مدیریت (`/admin`)
- 📊 آمار ربات
- 🎛 **مدیریت دکمه‌ها:** روشن/خاموش، تغییر اسم، رنگ، ایموجی پریمیوم، جابجایی
- 📦 **پلن‌ها:** نام، قیمت، مدت (روز)
- 🛰 **اتصال پنل پاسارگارد** و تست اتصال و ساختار
- 🗂 **پنل‌های فروخته‌شده:** تعلیق، تمدید، رمز جدید، حذف
- 🧾 **رسیدهای در انتظار:** ✅ تأیید / ❌ رد
- 👥 **کاربران:** موجودی، مسدود و آزاد کردن
- ⚙️ **تنظیمات ربات**
- 📢 **پیام همگانی**
- 📣 **گزارش:** ارسال رویدادها به گروه با تاپیک‌های جدا

### 🤖 بخش خودکار
- ⚠️ **هشدار حجم:** اطلاع به کاربر روی ۸۰٪، ۹۵٪ و ۱۰۰٪ مصرف
- 📡 **مانیتور پنل:** اگر پنل از دسترس خارج شود به ادمین‌ها خبر می‌دهد
- 💾 **بکاپ خودکار:** نسخه gzip از دیتابیس
- ⏳ **انقضا:** غیرفعال‌سازی خودکار ادمین‌های منقضی‌شده روی پنل
- 📱 **مینی‌اپ تلگرام:** سرویس جدا با aiohttp

## ⚡ نصب سریع
روی سرور Ubuntu/Debian با دسترسی root:

```bash
apt-get update -y && apt-get install -y git
git clone https://github.com/capitan-bot/panel-seller.git /opt/pgbot
bash /opt/pgbot/menu.sh
```

گزینهٔ **1** را بزن. نصب‌کننده این‌ها را می‌پرسد:

| سوال | توضیح |
|---|---|
| 🤖 توکن ربات | از @BotFather |
| 🆔 آیدی عددی ادمین | از @userinfobot (چند آیدی با کاما) |

بعد در ربات `/admin` ← «اتصال پنل» را بزن و آدرس و یوزر و رمز پاسارگارد را وارد کن.

> ⚠️ حتماً از فایل `.env` (به‌خصوص `ENCRYPTION_KEY`) بکاپ بگیر. بدون آن رمز ذخیره‌شدهٔ پنل خوانده نمی‌شود.

---

## 🔧 نصب دستی

```bash
git clone https://github.com/capitan-bot/panel-seller.git /opt/pgbot
cd /opt/pgbot
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
./venv/bin/python -m bot.main
```

مقدار `ENCRYPTION_KEY` را با این دستور بساز:

```bash
python3 -c "from cryptography.fernet import Fernet;print(Fernet.generate_key().decode())"
```

## 🔄 آپدیت دستی

```bash
cd /opt/pgbot
git pull
./venv/bin/pip install -r requirements.txt
systemctl restart pgresellerbot
```

## 🔑 متغیرهای `.env`

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_TELEGRAM_IDS` | آیدی عددی ادمین‌ها (با کاما) |
| `ENCRYPTION_KEY` | کلید رمزنگاری Fernet |
| `REPORT_CHAT_ID` | اختیاری، گروه گزارش |

---

## 🎨 تغییرات ظاهری

| قابلیت | توضیح |
|---|---|
| ✨ ایموجی پریمیوم | جایگزینی ایموجی ساده با ایموجی پریمیوم تلگرام |
| ✏️ تغییر نام دکمه‌ها | عوض کردن عنوان دکمه‌ها |
| 🌈 رنگ دکمه‌ها | آبی (primary)، سبز (success)، قرمز (danger) |
| ↕️ جابجایی | تغییر ترتیب دکمه‌ها |

**نکات:**
- رنگ و ایموجی با فیلدهای `style` و `icon_custom_emoji_id` تلگرام روی دکمه‌ها می‌نشیند
- ایموجی پریمیوم فقط وقتی نمایش داده می‌شود که تلگرام برای آن ربات اجازه بدهد
- به تلگرام به‌روز نیاز دارد

## 📣 گروه گزارش
یک سوپرگروه با تاپیک (Forum) بساز، ربات را ادمین کن و در ربات `/admin` ← «گزارش» را بزن. رویدادها در تاپیک‌های جدا می‌آیند:

| تاپیک | رویداد |
|---|---|
| 🧪 تست | دریافت پنل تست |
| 🛒 خرید | خرید پنل |
| ➕ حجم اضافه | خرید حجم اضافه |
| 💰 کیف پول | شارژ و تراکنش‌ها |
| 💾 بکاپ | فایل بکاپ دیتابیس |
